# AGENTS.md

## Правила разработки

### Память

- Запрещено использовать `malloc()` и динамическое выделение памяти.
- Запрещено использовать `new`, `delete`, `realloc`, `free` и любые другие функции динамического выделения.
- Для хранения данных используйте статические массивы, глобальные константы или объекты (stack/flash RAM, определённые до запуска).
- Нельзя создавать объекты неинтегральных типов внутри методов и функций. Все локальные переменные должны быть интегрального типа; составные данные — только в статическом или глобальном хранилище.

### Комментарии

- Комментарии в коде можно писать только по-русски.

### Параметры функций

- Большие составные объекты (структуры, классы, массивы) передавать только по указателю или ссылке.

### Статические методы

- Запрещено использовать статические методы в классах.
- Код, не зависящий от состояния объекта, писать как свободные функции вне класса.

### Состояние устройств

- Каждый класс, описывающий устройство, обязан иметь собственную структуру состояния (например, `RelayState` для `Relays`) и методы `getState()` / `setState()`.
- При добавлении нового класса, описывающего устройство, всегда добавлять структуру состояния вместе с методами `getState()` / `setState()`.
- Состояние устройства считывать и обновлять только через методы `getState()` / `setState()`. Прямой доступ к полям структуры состояния извне запрещён.
